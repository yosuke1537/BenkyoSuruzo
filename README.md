# 勉強するぞ（BenkyoSuruzo）

Android 向けの語学学習サポートアプリです。

中国語学習アプリなどの画面上に表示されたテキストを、タップ操作で緑色の帯に置き換えて
一時的に「隠す」ことで、自分で思い出す・答え合わせをする自己テスト（暗記）を支援します。

## 主な機能

- **マスクモード**
  - 画面上のテキストをタップすると緑色の帯で隠れ、もう一度タップすると元に戻ります。
  - 単語ごと／文章ごとに、隠す範囲・戻す範囲を設定できます。
- **フローティングボタン「遮」**
  - 対象アプリが前面にあるときだけ表示され、ワンタップでマスクモードを開始します。
  - ドラッグで好きな位置に移動でき、位置は端末に記憶されます。
- **円形ボタン「显」**
  - マスクモード中に表示され、タップするとマスクモードを終了します。
- **マスク対象外の言語**
  - 母語や UI 言語など、隠したくない言語を除外できます。
- **対象アプリの指定**
  - フローティングボタンを表示するアプリを指定できます。

## 使い方

1. 設定画面で「勉強するぞ対象アプリ」に学習で使うアプリを追加します。
2. 「フローティングボタンを表示する」を ON にし、アクセシビリティサービスを有効にします。
3. 学習アプリを開くと「遮」ボタンが表示されます。
4. 「遮」をタップするとマスクモードが始まります。隠したい文字列をタップすると緑色の帯で隠れます。
5. 緑色の帯をもう一度タップすると元に戻ります。
6. 「显」ボタンをタップするとマスクモードが終了します。

## 注意事項

### 「显」ボタン表示中は画面がロックされたように見えます
マスクモード中は画面に赤い円形の「显」ボタンが表示され、**画面がロックされたように
見えることがありますが、これは正常な動作です**。

マスクモード中は、誤操作を防いで「文字を隠す操作」に集中できるよう、タップがマスク操作に
割り当てられ、画面のスクロールも抑止されます。

通常の操作に戻したいときは、**「显」ボタンをタップしてマスクモードを終了してください**。

### その他の注意
- 本アプリは Android の**アクセシビリティサービス**を使って、他のアプリの画面上のテキストを
  読み取ります。初回設定時にサービスを有効にする必要があります。
- アクセシビリティサービスは画面上のテキストを読み取るため、**個人情報や機密情報が表示された
  画面ではご注意ください**。

## 必要な権限
- アクセシビリティサービス（画面テキストの読み取り、オーバーレイ表示）
- 通知（マスクモード中の常駐通知）

## 動作環境
- Android 8.0（API 26）以上

## ビルド
リポジトリをクローンし、Android Studio で開いてビルドしてください（JDK が必要です）。
